## Overview

A curated set of configuration schemas and community plugins tailored for connecting Obsidian vaults with static Astro sites.

### Features
- **Page Bundle Support**: Colocates images pasted with `Ctrl + V` right beside Markdown files.
- **Strict Frontmatter**: Validates `pubDate`, `tags`, and `draft` statuses automatically.
- **1-Click Publishing**: Direct sync to GitHub through Obsidian Git.

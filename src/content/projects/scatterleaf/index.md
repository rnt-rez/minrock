## Overview

**ScatterLeaf** is a modern alternative to traditional comment widgets. Instead of heavy `<iframe>` embeds that cause layout shifts and scroll stutter, ScatterLeaf uses native **Shadow DOM Web Components**.

### Key Features
- **Zero Iframe**: Native DOM rendering with silky-smooth scrolling.
- **Theme Matching**: Seamlessly blends into light, dark, and custom palettes.
- **Secure**: Uses GitHub Discussions as an authenticated backend.
